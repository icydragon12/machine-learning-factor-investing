# Project Instructions

This project is an educational React/Vite site for finance professionals learning machine learning for factor investing.

## Working rules

- Keep explanations finance-native, concise, skeptical, and practical.
- Do not write academic walls of text.
- Do not fabricate citations or data.
- Do not copy text from mlfactor.com or any other copyrighted source.
- Use `docs/source-pack/` as background reference only.
- When adding content, prefer short cards, hover panels, comparison tables, and investor-translation sections.
- Run `npm run build` before considering work complete.
- Keep the GitHub Pages base path aligned with the deployed repo.

## Context discipline

- Before making large changes, inspect only the relevant files.
- Do not recursively read the entire repository unless necessary.
- Use `docs/source-pack/index.md` to decide which reference file is relevant.
- Prefer targeted edits over broad rewrites.

## Content standards

- Lead with the conclusion.
- Prefer probabilistic language over point-estimate language.
- Emphasize similarity, difference, implication, and falsification.
- Treat ML as a tool for structuring uncertainty, not a promise of prediction.
