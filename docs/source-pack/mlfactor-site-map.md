# MLFactor Site Map

This is a compact outline of the site architecture and the educational flow.

## Core sections

- Hero / thesis
- Why this matters
- Algorithm map
- Finance use cases
- Ensemble mindset
- Glossary
- Resources / next steps

## Concept flow

1. Start with the claim that point estimates are too fragile for markets.
2. Show why ML is useful for uncertainty, nonlinearities, and regime-aware thinking.
3. Introduce the main algorithm families at a high level.
4. Translate each model family into an asset-manager use case.
5. Reinforce that validation and leakage control matter more than model glamour.
6. End with a practical roadmap and future modules.

## Supporting ideas

- Replace single-number certainty with distributions and ranges.
- Treat factor investing as a noisy measurement problem, not a clean optimization exercise.
- Use analogies and comparison frames to make outputs decision-useful.
- Show where each method fits, and where it fails.
